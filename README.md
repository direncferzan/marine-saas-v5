# 🌊 Marine SaaS V5: The Watchdog Edition

A high-performance, modern multivendor marketplace framework designed for scale and speed. This is not just another template; it is a fully integrated **SaaS ecosystem** featuring a unique administrative monitoring system and a seamless user experience[cite: 9].

## 🛠 Core Architecture

*   **Logical Depth:** Built with a robust logical structure of over 2,000 lines of custom-engineered code to handle complex marketplace flows.
*   **Role-Based Access Control (RBAC):** Native support for **Customer**, **Restaurant Owner**, and **Admin** roles, each with dedicated dashboards and permissions[cite: 9].
*   **The Watchdog Terminal:** A signature administrative console for real-time system monitoring, node tracking, and master control over all restaurant operations.

## ✨ Key Features

*   **Modern UI Engine:** Leveraging Tailwind CSS and the Inter font family for a sleek, "Yemeksepeti Redesign" inspired aesthetic.
*   **Smart Product Customization:** Advanced modal system for item modifiers (extra toppings, variations) with real-time price calculation[cite: 8, 9].
*   **Dynamic Shop Management:** Restaurant owners can manage menus, toggle shop status (Open/Closed), and track orders through a specialized operation panel.
*   **Order Simulation:** Built-in simulation flow for fast-checkout testing and role-based management without backend dependencies[cite: 9].

## 💻 Technical Stack

*   **Frontend:** React.js with TypeScript.
*   **Styling:** Modern CSS3 with custom variables and Tailwind utilities.
*   **Icons:** Lucide-React for a consistent and professional icon set.
*   **Routing:** React Router DOM for seamless SPA navigation.
*   **State Management:** React Hooks (useState, useEffect) with LocalStorage persistence.
